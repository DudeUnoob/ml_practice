# Workbook

These files are intentionally incomplete. You are supposed to edit them.

Run:

```bash
python3 tools/coach.py list
python3 tools/coach.py show 01
python3 tools/coach.py check 01
```

The checker imports functions from `workbook/steps/`. If a function still raises
`NotImplementedError`, implement it and run the checker again.

## Important

Do not try to complete a whole file before running the checker. Implement one
function, run the checker, read the next failure, and continue.

## Reference solutions

After trying, compare with `solutions/steps/`:

```bash
python3 tools/coach.py solution 01
```

The solutions are not the starting point. They are a mirror after you have done
the work.
